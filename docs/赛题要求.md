# 赛题要求

## 灵动小鱼游动

**上海波克 Vibe Jam AI 游戏开发比赛**

`捕鱼游戏` · `鱼群行为` · `AI 决策` · `交互原型`

---

## 一、业务场景

在捕鱼游戏渔场中，小型鱼种作为高频出现的环境与捕获目标，需要通过更自然、更丰富的游动轨迹，提升渔场的观感和活跃度。

## 二、问题描述

当前渔场内小型鱼种的移动轨迹和游动方式较为单一，多数鱼只按照固定路径或简单队列移动，缺少鱼群聚散、转向、绕行、穿插等灵动表现。

本赛题希望设计一套小鱼游动组合方案，实现以下目标：

- 刷鱼时形成更美观、更自然的鱼群动态；
- 支持鱼群聚散、转向、绕行和穿插等多样化运动；
- 玩家点击屏幕后，能够影响附近鱼种的原有轨迹；
- 呈现类似“被惊动后游走”的交互效果。

## 三、AI 要求

AI 可应用于以下两个方向：

| 应用方向 | 具体内容 |
| :-- | :-- |
| **游动策略生成与调整** | 生成或调整鱼群队形、路径变化、聚散节奏和避让反应 |
| **鱼群行为决策** | 根据玩家点击位置、鱼群距离和鱼种特性，决定鱼只转向、加速、散开或重新回归队形 |
