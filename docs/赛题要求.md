# 灵动小鱼游动

## 业务场景

在捕鱼游戏渔场中，小型鱼种作为高频出现的环境与捕获目标，需要通过更自然、更丰富的游动轨迹提升渔场观感和活跃度

## 问题描述

当前渔场内小型鱼种的移动轨迹和游动方式较单一，多数鱼只按照固定路径或简单队列移动，缺少鱼群聚散、转向、绕行、穿插等灵动表现。希望设计一套小鱼游动组合方案，让刷鱼时能形成更好看的鱼群动态；同时支持玩家点击屏幕后影响附近鱼种原有轨迹，呈现类似“被惊动后游走”的交互效果

## AI 要求

AI 可用于生成或调整小鱼的游动组合策略，例如鱼群队形、路径变化、聚散节奏和避让反应；也可作为行为决策模块，根据玩家点击位置、鱼群距离和鱼种特性，决定鱼只转向、加速、散开或重新回归队形

## 作品要求

### 1. 可运行的作品

- **格式：** 在线访问链接 或 工程压缩包（支持 HTML/JS、Unity WebGL 等）
- **内容说明：** 基于 AI 编程工具产出的游戏/应用可交互原型，需贴合对应业务赛题要求。优先推荐 Web 单页形式（独立 HTML+CSS+JS），方便评审直接在线打开体验。

### 2. Prompt 对话日志

- **格式：** TXT / JSON / MD 文档
- **内容说明：** 需提交从 AI 开发工具导出的完整 Prompt 对话日志，包含全部人工指令输入、AI 代码生成及迭代回复全过程，不得删减关键记录。

### 3. 作品说明文档

- **格式：** 文字说明（字数 ≤ 500 字）
- **内容说明：** 需包含作品名称、解决的核心业务痛点、核心玩法/功能亮点、项目创意设计；简述 AI 协作开发过程，说明 AI 在代码生成、功能迭代、方案取舍优化中的核心价值与亮点。

## 作品补充要求
